\chapter{前言}

这是我的第一个 OS 内核。既然没有经验，看不懂别人的操作系统，只好自己从零搭一个了。或许很多东西并不是最佳实践，但是能跑起来才是最重要的。

这个操作系统没有使用任何来自第三方的代码，不过使用了 OS 中常见的概念和抽象，例如 VFS 等。

这个 OS 完全采用 C++ 实现。这是一个与现有操作系统都不相同的决定，在\cref{chap:why_cpp}中，我详细解释了这么做的原因。

在这篇文档中，我将以 RISC-V 作为例子，介绍操作系统的启动流程以及各个子系统的实现方式。LoongArch 的支持是由条件编译指令 \texttt{#ifdef __loongarch__} 控制的，在此不作过多介绍。
