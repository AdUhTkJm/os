\chapter{前言}
\label{chap:preface}

这是我的第一个 OS 内核。既然没有经验，看不懂别人的操作系统，只好自己从零搭一个了。这个操作系统没有基于已有的 OS 代码进行开发，不过使用了 OS 中常见的概念和抽象，例如 VFS 等，同时使用了少量的第三方代码，在 \cref{chapter:3rdparty} 中列出。或许很多东西并不是最佳实践，但是能跑起来才是最重要的。

从项目数据上来看，\input{data/git_summary.tex}。请注意这里的“代码行数”包括所有被 git 统计的文件，例如这篇文档也在其中：LaTeX 代码也是代码。

从语言上来看，这个 OS 完全采用 C++ 实现\footnote{这里面有个微型 libc，这个是纯 C 的，但占比可以忽略不计。}。请注意这是 C++20，并且采用了许多 gcc/clang 独有的扩展；微软的 MSVC 或旧版本的编译器是无法编译它的。这是一个与几乎所有现有操作系统都不相同的决定。在我看来，操作系统使用 C 主要是历史原因，而 C++ 不失为一种好的选择。更重要的一点是，我对它比较熟悉。至于 Rust，我个人感觉它“不够自由”，所以我不喜欢它。在\cref{chap:why_cpp}中，我介绍了在没有 C++ runtime 时的一些 workaround 和一些好用的特性。

在这篇文档中，我将以 RISC-V 作为例子，介绍操作系统的启动流程以及各个子系统的实现方式。其中内容较多的部分，我将会单独提出为一章来介绍，例如文件系统所在的\cref{chap:fs}；而其他较为简单的子系统则合并在一章之中，也就是\cref{chap:subsystem}。LoongArch 的支持准备由条件编译指令 \cpp{#ifdef __loongarch__} 控制，但我尚未开始。

这篇文档在一定程度上也算是我的 OS 学习笔记，因此语言上不会非常正式，而且有不少对实现原理的介绍。此外，一部分术语可能会有中英混用的情况。
