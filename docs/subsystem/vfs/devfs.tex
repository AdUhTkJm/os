\subsection{devfs}
\label{subsec:devfs}

这是将各类设备当做虚拟 inode 而构成的文件系统。下面我会介绍我实现的各种设备。

\subsubsection{console}

对调试而言最重要的设备。它的写可以直接靠 OpenSBI 完成，但是读则需要和 UART 设备交流，而且需要启动 PLIC 来接收中断。这是刚开始启动时就已经完成的事情，具体可见\cref{sec:boot}。

\subsubsection{sda}

这是一个 block device。第一个被命名为 sda，之后的自然是 sdb, sdc 等等。

它对\cref{sec:virtio}提到的设备驱动进行了一层封装。VirtIO 只能按照 512 字节的整数倍访问，而这个 inode 可以任意指定偏移量和长度。

它还有缓存功能。我们经常会连续读取或写入硬盘的同一块地方，因此将它们缓存在内存里会有肉眼可见的性能提升。
